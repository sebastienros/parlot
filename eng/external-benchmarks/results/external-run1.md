# External benchmarks, run 1

Fluid and NCalc (runtime grammar, `NCalcParse.Fluent`) rows are valid: every variant ran its own Parlot assembly.
**The `NCalcParse.Generated` rows are not**: MSBuild skipped recompiling NCalc's generated parser for most variants,
which then ran another variant's generated code (fixed in `run.sh`, see `external-run2.md` for those rows).

Variants: `main` (8a5f6b1), `*-offset` use Fluid with `patches/fluid-string-literal-offset.patch`, `pratt-ncalc` uses
`patches/ncalc-pratt.patch`, `memo-fluid` uses `patches/fluid-memoize.patch`. 2 rounds, alternating order, in-process,
6 warmup and 20 measured iterations of 250 ms. x64 4-core VM (Xeon, AVX-512), .NET 10.0.14, BenchmarkDotNet 0.15.8.
